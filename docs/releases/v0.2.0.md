# Loom v0.2.0

Loom v0.2.0 expands the project workbench into a richer Agent workspace: Chat can now generate images, sessions can keep running while you switch away, projects can manage Subagents / Skills / MCP resources, scheduled tasks have stronger live execution support, and macOS packaging is more reliable.

## Highlights

- Added text-to-image and reference image-to-image workflows directly in Chat.
- Added configurable image providers for GPT-Image2 / OpenAI, Nano Banana 2, and SeeDream / Volcengine Ark. Base URL, API key, and model ID remain configurable for relay and gateway services.
- Added image generation controls for provider, reference images, aspect ratio, style preset, output format, and optional confirmation.
- Added image job cards with progress states, generated image preview, download, retry, metadata, and reuse-as-reference actions.
- Added GPT-Image2 waiting guidance in the AI reply area because high-quality generation can take about 180 seconds.
- Added project resource management for Subagents, project-visible Skills, and project-visible MCP servers.
- Added Subagent editing with model selection, tool permissions, enablement, instructions, and bound Skills.
- Added enhanced scheduled tasks with Subagent / Skills bindings, run-now execution, pause / enable controls, live output, execution history, and navigation back to the full session.
- Added Feishu / Lark project bot channel settings with DM / group policies, allowlists, permission modes, session bindings, and audit logs.
- Added model tier mapping, custom model entries, context window settings, context usage display, and `/compact` suggestions.
- Added MP4 and local file preview improvements across attachments, Markdown links, and project file browsing.

## Fixes and Improvements

- Chat input now supports keyboard up / down navigation through previous user messages while preserving the current draft.
- Project Files directories can now be opened from the right-click menu in the system file manager.
- Switching sessions no longer interrupts an in-progress task; the sidebar shows which sessions are still running.
- Active runs are tracked across project events, session events, and stop / interruption flows.
- Project creation now saves the project description correctly.
- Project creation only uses the selected folder name as the project title when the title is empty.
- Large attachment and PDF sends now show a confirmation prompt to reduce accidental context bloat.
- macOS packaging now verifies bundled Node.js, Claude CLI, and native modules for the target architecture.
- Startup diagnostics now write main-process logs and show clearer errors when the bundled service cannot start.
- README and README.zh-CN were aligned and updated for the current release.

## Known Limitations

- Windows packaging is configured but is not part of this generated release artifact set.
- Image provider quality, latency, and supported parameters depend on the configured upstream service.
- Feishu / Lark bot usage requires a valid self-built app and project-level channel configuration.
