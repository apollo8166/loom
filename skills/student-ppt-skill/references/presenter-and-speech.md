# 演讲者模式 + 讲稿/问答

## 演讲者模式（HTML 展示稿自带）

放映 `student-ppt.html` 时的快捷键：
- `← → / 空格 / PgUp PgDn`：翻页　`Home / End`：首/末页　`F`：全屏　`O`：总览缩略图
- **`S`：打开演讲者窗口**——一个独立小窗，含 4 张可拖动卡片：
  - **当前页**（缩略实时预览）、**下一页**（提前看）、**逐字稿**（大字、读 `notes`）、**计时器**（已用时）
  - 卡片可拖动，位置记在 localStorage；窗口里的"上/下一页"按钮直接控制主窗口（postMessage，兼容 `file://`）
- `?preview=N`：只显第 N 页、无 chrome（演讲者卡片和总览内部用）。

> 实际用法：投影/全屏放主窗口给观众，自己电脑上按 `S` 开演讲者窗口看逐字稿和计时。
> 逐字稿来自每页的 `notes` 字段——所以 `notes` 要按"逐字稿三铁律"写。

## 逐字稿三铁律（写进 notes / speech.md）

1. **不是全文，是提示信号**：写关键词和过渡句，不要写成一字不漏的稿子。**核心词加粗**（`**词**`），过渡句独立成段。
2. **节奏**：每页 150–300 字 ≈ 2–3 分钟；页越多每页越短。
3. **口语不书面**：说"所以""这个"，不说"因此""该"；像学生站着能自然说出口的话。

## speech.md 格式模板

```markdown
# 演讲稿（逐字稿 · 提示信号版）
> 规则：口语不书面；核心词加粗；过渡句独立成段；每页 150–300 字 ≈ 2–3 分钟。

## 第 1 页 · {action_title}
- 本页主张：{一句话结论}
**开场**：……（说到 **关键词**）。
这里解释……（一段一个意思，别堆）。
**过渡**：接下来看……（独立成段，引出下一页）。
⏱ 约 2 分钟

## 第 2 页 · {action_title}
……
```

## qa.md 格式模板

```markdown
# 可能的提问与参考回答
> ≥3 个；答案口语化、30–60 秒能说完；不确定处写"待补充/需老师确认"，**不编造**数据或出处。

## Q1（角度：方法 / 证据 / 反例 之一）
问题：……
参考回答：……
⚠ 若被追问 {x}：可补充 {y}；数据/出处没有就说"这点我还需要再核实"，不要硬编。

## Q2 …
## Q3 …

## 我主动想补充的一点
……（展示思考深度，但同样不编造）
```

生成时：`speech.md` 每页对应 deck 一页；`qa.md` 至少 3 题，覆盖老师常问的方法/证据/反例/意义角度。
两者都要过反编造闸门（见 SKILL.md 质量标准）。
