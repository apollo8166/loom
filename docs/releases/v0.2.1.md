# Loom v0.2.1

Loom v0.2.1 is a stability release for the image-generation and workbench attachment flows. It keeps provider configuration flexible while making Agent-triggered image generation behave consistently in Chat.

## Highlights

- Added Claude Agent SDK image-generation tool integration for Loom Chat. The model can call Loom's image tool during normal global Chat or project Chat turns without switching the UI into image-generation mode.
- Image tool results now render consistently as `ImageJobCard` records instead of mixing task cards and Markdown images.
- Agent-created image jobs are stored separately from manual image-mode jobs, so the image-generation mode history remains focused on manually created jobs.
- Image job cards now show provider/model metadata, generated image preview, download, and result details for Agent-created images.
- Markdown image URLs in chat now support click-to-preview with the existing file preview panel.
- The global Chat and project Chat workbench input area now accepts dragged files and uploads them through the existing attachment flow.
- macOS DMG artifacts are Developer ID signed, notarized, stapled, and verified with Gatekeeper before release.

## Fixes and Improvements

- Fixed MCP image tool result parsing when the SDK wraps the JSON payload in `content: [{ type: "text", text: ... }]`.
- Fixed a race where `tool_use_summary` could occupy the image tool result slot before the real `jobId` result arrived.
- Removed image URLs from the structured tool result returned to the model, reducing duplicate Markdown image output in assistant replies.
- Added uniform image-tool status cards for missing or failed job lookups instead of falling back to Markdown rendering.
- Fixed Markdown image filename and MIME inference for `/api/files/serve/...` URLs.
- Tightened drag-and-drop handling so Loom only intercepts real file drops and does not hijack ordinary text drags.
- Centralized the visible application version used by the left navigation footer and the Guide dialog.

## Downloads

macOS builds for this release:

- Apple Silicon: `loom-cc-v0.2.1-mac-arm64.dmg`
- Intel: `loom-cc-v0.2.1-mac-x64.dmg`

Release artifacts are built without local user databases, provider credentials, API keys, or user settings. User data is created under the app data directory after first launch.

## Known Limitations

- Windows packaging is configured but is not part of this generated release artifact set.
- Image provider quality, latency, and supported parameters depend on the configured upstream service.
- Agent-triggered image generation depends on the active image provider configuration and available provider API key.
