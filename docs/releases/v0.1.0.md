# Loom v0.1.0

Initial open-source baseline for Loom.

## Highlights

- Desktop AI workbench built with Next.js, Electron, React, and Claude Agent SDK.
- Global chat and project chat share the same runtime flow.
- Project workspaces include file context, memory, schedules, and local runtime settings.
- Built-in Skills catalog is read from the repository `skills/` directory.
- Skill Builder creates concise, high-quality Loom Skills with user-friendly discovery prompts.
- Student PPT Skill is included as a built-in package.
- Ask-user confirmation UI supports permission prompts and structured user choices.
- Chat auto-scroll behavior now lets users scroll upward without being forced back to the bottom.
- macOS app icon and title-bar logo use the Loom rounded-square icon.

## Downloads

macOS builds generated for this release:

- Apple Silicon: `loom-cc-v0.1.0-mac-arm64.dmg`
- Intel: `loom-cc-v0.1.0-mac-x64.dmg`

The current macOS builds are unsigned and not notarized. Gatekeeper may show a warning on first launch.

## Known Limitations

- Built packages currently warn if bundled `build/claude-cli/` and `build/node-runtime/` are missing. Users may need a local Node.js runtime and Claude CLI/SDK authentication depending on their setup.
- Local data formats, Skill workflows, and provider settings may still change before `1.0.0`.
- Windows packaging is configured but not part of this first generated artifact set.
