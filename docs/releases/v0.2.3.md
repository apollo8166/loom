# Loom v0.2.3

Loom v0.2.3 is a patch release for the image generation entry experience.

## Highlights

- The image generation button is now visible by default in the Chat / Workbench toolbar.
- Users can open the image generation mode before configuring a provider.
- When an image prompt is submitted without a configured provider or API key, Loom now shows a direct Settings guidance message.

## Fixes and Improvements

- Decoupled image generation entry visibility from the image provider enable/configuration state.
- Kept the send button active in image generation mode so missing configuration can produce an actionable prompt instead of a hidden or disabled workflow.
- Aligned the image generation API error message with the new Settings-first guidance.

## Downloads

macOS builds for this release:

- Apple Silicon: `loom-cc-v0.2.3-mac-arm64.dmg`
- Intel: `loom-cc-v0.2.3-mac-x64.dmg`

Release artifacts are built without local user databases, provider credentials, API keys, or user settings. User data is created under the app data directory after first launch.

## Known Limitations

- Windows packaging is configured but is not part of this generated release artifact set.
- Image provider quality, latency, and supported parameters depend on the configured upstream service.
