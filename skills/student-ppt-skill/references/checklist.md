# 交付质量清单（P0–P3）

交付前对照；`render-check.mjs` 自动查 P0 部分。

## P0 · 红线（违反必须修）
- [ ] **不编造**：无杜撰事实；缺的写"待补充"
- [ ] **不泄隐私**：无 API Key / 姓名学校发给图片服务商；`render-check` 无告警
- [ ] **能渲染**：HTML 双击能放映，无空白页；PPTX 路径则 `validate-pptx-html` 0 违规

## P1 · 结构与可讲性
- [ ] 每页一个核心观点；标题是**结论句**，不是"背景/总结"。
- [ ] 正文每页约 ≤80 字、要点 ≤6 条；不满屏文字。
- [ ] 页序符合场景（见 student-ppt-patterns.md）；封面基本信息齐（姓名/班级/学校或已确认匿名）。
- [ ] 每页有逐字稿（`notes`），讲稿能自然衔接；≥3 个可能提问。
- [ ] 正文字号够大，投影后能看清。

## P2 · 视觉一致与质量
- [ ] 用了锁定主题，没乱改 hex；一个主色 + 一个强调色。
- [ ] 对比度足够、无文字溢出/遮挡/低对比；配图无明显裁切变形。
- [ ] 优先结构化布局（时间线/对比/结构图/引用/反思），少堆 bullet。
- [ ] 对照 `anti-slop.md`：无紫渐变、无 emoji 刷屏、无假数据。

## P3 · 打磨
- [ ] 标题/正文用词口语、贴年级；无中英混排的翻译腔。
- [ ] 讨论题/Q&A 有思考深度（见 content-depth.md）。
- [ ] 文件命名清晰，最终回复列出所有产物路径和剩余"待补充"项。
