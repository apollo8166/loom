# Loom v0.2.2

Loom v0.2.2 is a patch release focused on attachment reliability, especially PDF handling in Chat and the runtime SDK.

## Highlights

- PDF uploads now try text extraction first, then fall back to `pdfjs` text reading when the primary parser returns nothing.
- Image-only or scanned PDFs are treated as unreadable instead of being forwarded as ambiguous chat placeholders.
- Chat attachments now keep a consistent presentation path with `PDF Text` and `PDF Unreadable` labels.
- The current app version is shown in the left navigation footer and Guide dialog.

## Fixes and Improvements

- Removed the old SDK PDF document fallback that could make the model search the workspace for uploaded attachments.
- Blocked unreadable PDFs before chat submission so the user gets a direct explanation instead of a failed turn.
- Kept uploaded PDFs available for preview and download while separating readable text from the original file.

## Downloads

macOS builds for this release:

- Apple Silicon: `loom-cc-v0.2.2-mac-arm64.dmg`
- Intel: `loom-cc-v0.2.2-mac-x64.dmg`

Release artifacts are built without local user databases, provider credentials, API keys, or user settings. User data is created under the app data directory after first launch.

## Known Limitations

- Windows packaging is configured but is not part of this generated release artifact set.
- Image provider quality, latency, and supported parameters depend on the configured upstream service.
